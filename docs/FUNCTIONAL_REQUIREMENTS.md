## 1. Роли пользователей и права доступа

### 1.1 Роли системы

| Роль | Описание |
|---|---|
| `guest` | Незарегистрированный посетитель |
| `client` | Верифицированный пользователь-клиент |
| `provider` | Верифицированный представитель автосервиса |
| `expert` | Верифицированный мастер или специалист |
| `admin` | Администратор платформы |

### 1.2 Матрица прав доступа

| Действие | guest | client | provider | expert | admin |
|---|:---:|:---:|:---:|:---:|:---:|
| Просмотр карты и карточек | ✓ | ✓ | ✓ | ✓ | ✓ |
| Просмотр отзывов | ✓ | ✓ | ✓ | ✓ | ✓ |
| Просмотр тикетов | ✓ | ✓ | ✓ | ✓ | ✓ |
| Написание отзыва | — | ✓ | — | — | ✓ |
| Создание тикета | — | ✓ | — | — | ✓ |
| Ответ на тикет | — | — | ✓ | ✓ | ✓ |
| Ответ на отзыв | — | — | ✓ (свой) | — | ✓ |
| Управление карточкой сервиса | — | — | ✓ (своя) | — | ✓ |
| Просмотр расписания записей | — | — | ✓ (своё) | — | ✓ |
| Запись на приём | — | ✓ | — | — | ✓ |
| Модерация отзывов | — | — | — | — | ✓ |
| Управление пользователями | — | — | — | — | ✓ |

### 1.3 Правило одной роли

Один аккаунт = одна основная роль. Владелец автосервиса не может одновременно писать отзывы как клиент через тот же аккаунт. Если человек хочет оставить отзыв как клиент — нужен отдельный аккаунт, привязанный к другому номеру телефона.

## 2. Авторизация и верификация

### 2.1 Регистрация клиента

**FR-2.1.1** Регистрация доступна через номер телефона (основной способ) или email.

**FR-2.1.2** При регистрации по телефону:
- Пользователь вводит номер в формате +7XXXXXXXXXX
- Система отправляет SMS с 6-значным кодом подтверждения
- Код действителен 5 минут
- После 3 неверных попыток — блокировка на 15 минут
- Один номер телефона = один аккаунт, повторная регистрация на тот же номер невозможна

**FR-2.1.3** При регистрации по email — стандартное подтверждение через письмо со ссылкой. Email-аккаунт без привязки телефона ограничен в правах: не может писать отзывы до добавления телефона.

**FR-2.1.4** Обязательные поля при регистрации: имя (отображается в профиле), номер телефона или email. Фамилия — опционально.

### 2.2 Уровни верификации клиента

**Уровень 0 — гость.** Не авторизован. Только просмотр.

**Уровень 1 — телефон подтверждён.** Может писать отзывы и создавать тикеты. В отзыве отображается бейдж «Верифицирован».

**Уровень 2 — Госуслуги (ЕСИА).** Авторизация через OAuth ЕСИА. Отзывы получают бейдж «Подтверждена личность». Реальное имя подставляется автоматически из ЕСИА, пользователь не может его изменить. Реализуется в фазе 2.

### 2.3 Регистрация и верификация поставщика

**FR-2.3.1** Поставщик регистрируется как обычный пользователь, затем подаёт заявку на роль `provider`.

**FR-2.3.2** Процесс верификации поставщика:
1. Поставщик указывает название организации и ИНН
2. Прикладывает документ подтверждающий право управления (выписка ЕГРЮЛ, свидетельство)
3. Модератор проверяет документы в течение 48 часов рабочего времени
4. После одобрения — аккаунт получает роль `provider` и привязывается к карточке сервиса

**FR-2.3.3** Один поставщик может управлять несколькими карточками (сеть сервисов) — все привязываются к одному аккаунту.

### 2.4 Верификация эксперта

**FR-2.4.1** Мастер или специалист подаёт заявку на роль `expert`.

**FR-2.4.2** Верификация эксперта:
- Указывает специализацию (кузовной мастер, электрик, диагност и т.д.)
- Прикладывает подтверждение: диплом, свидетельство о квалификации, или письмо от работодателя
- Модератор проверяет в течение 48 часов

**FR-2.4.3** Эксперт отображается в ответах на тикеты с бейджем специализации.

### 2.5 Безопасность

**FR-2.5.1** Сессии хранятся через JWT-токены. Время жизни access-токена — 1 час, refresh-токена — 30 дней.

**FR-2.5.2** При смене номера телефона требуется подтверждение старого номера (если он ещё доступен) и нового.

**FR-2.5.3** Функция «Выйти на всех устройствах» инвалидирует все активные refresh-токены аккаунта.

## 3. Карта и геопоиск

### 3.1 Отображение карты

**FR-3.1.1** Главная страница открывается с картой Иркутска (стартовые координаты 52.2978° N, 104.2964° E, зум 12).

**FR-3.1.2** На карте отображаются точки-маркеры автосервисов. Цвет маркера кодирует рейтинг:
- Зелёный — рейтинг 4.0 и выше
- Жёлтый — рейтинг от 3.0 до 3.9
- Красный — рейтинг ниже 3.0 или менее 3 отзывов (недостаточно данных)

**FR-3.1.3** При зуме 12 и ниже применяется кластеризация: несколько близких точек объединяются в кластер с цифрой внутри. Кластер окрашивается по доминирующему рейтингу входящих точек.

**FR-3.1.4** При клике на маркер появляется всплывающий попап с краткой информацией: название, рейтинг, количество отзывов, главная категория услуг, кнопка «Подробнее». Клик на «Подробнее» открывает полную карточку.

**FR-3.1.5** Справа от карты (или снизу на мобильном) отображается список сервисов, синхронизированный с видимой областью карты. При прокрутке списка карта подсвечивает соответствующий маркер.

### 3.2 Геолокация пользователя

**FR-3.2.1** Кнопка «Найти рядом» запрашивает разрешение на геолокацию через браузерный API (Geolocation API).

**FR-3.2.2** При разрешении — карта центрируется на позиции пользователя, появляется синяя точка «Вы здесь», автоматически применяется фильтр по радиусу 3 км (по умолчанию).

**FR-3.2.3** Пользователь может изменить радиус поиска: 1 / 3 / 5 / 10 км — через переключатель над списком результатов.

**FR-3.2.4** В списке результатов рядом с каждым сервисом отображается расстояние от текущей позиции пользователя (например, «1.2 км»). Список сортируется по расстоянию по умолчанию.

**FR-3.2.5** Если пользователь отказал в геолокации — предлагается поле «Введите адрес или район» для ручного ввода начальной точки.

### 3.3 Поиск и фильтрация

**FR-3.3.1** Строка поиска поддерживает запросы вида:
- Название сервиса («Автосервис Иванова»)
- Тип услуги («шиномонтаж», «кузовной ремонт»)
- Адрес или район («Свердловский район», «ул. Байкальская»)
- Комбинированный («шиномонтаж Ленинский район»)

**FR-3.3.2** Поиск работает с задержкой 300 мс после последнего нажатия (debounce) — не перегружает запросами.

**FR-3.3.3** Фильтры применяются поверх текущей области карты и геопоиска:

| Фильтр | Тип | Значения |
|---|---|---|
| Категория услуг | Мультивыбор | Шиномонтаж, ТО, Кузовной, Мойка, Электрика, Диагностика, Автоподбор, Эвакуатор и др. |
| Марка авто | Мультивыбор | Список популярных марок + «Любая» |
| Рейтинг | Ползунок / чекбоксы | От 3.0 / От 4.0 / Только 5.0 |
| Режим работы | Чекбокс | Открыто сейчас |
| Онлайн-запись | Чекбокс | Только с онлайн-записью |
| Верифицирован | Чекбокс | Только верифицированные |
| Цена | Диапазон | Бюджетный / Средний / Премиум |

**FR-3.3.4** Все активные фильтры отображаются в виде тегов над результатами с кнопкой удаления каждого. Кнопка «Сбросить всё» очищает все фильтры разом.

**FR-3.3.5** Состояние фильтров и позиция карты сохраняются в URL (query params) — страница доступна для шаринга и индексации.

## 4. Карточка автосервиса

### 4.1 Публичная карточка — основная информация

**FR-4.1.1** URL карточки: `/services/[city]/[slug]` — например `/services/irkutsk/avtoservis-ivanova`. Slug генерируется из названия, уникален в рамках города.

**FR-4.1.2** Карточка содержит следующие блоки:

**Шапка:**
- Название сервиса
- Категория (Автосервис / Шиномонтаж / Мойка и т.д.)
- Бейдж «Верифицирован» если сервис прошёл верификацию
- Рейтинг: общая оценка + число отзывов + мини-график динамики
- Расстояние от пользователя (если геолокация разрешена)

**Контакты и адрес:**
- Полный адрес с кнопкой «Открыть в картах»
- Телефон с кнопкой «Позвонить» (tel: ссылка)
- Часы работы по дням недели, индикатор «Открыто / Закрыто сейчас»
- Ссылка на сайт (если указан)

**Услуги и цены:**
- Список услуг с ценами (если поставщик заполнил)
- Поддерживаемые марки авто — теги

**Фото:**
- Галерея: фото интерьера, оборудования, работ
- Фото из отзывов клиентов отображаются отдельным блоком

**Мини-карта:**
- Встроенный фрагмент Яндекс.Карт с маркером сервиса и кнопкой «Построить маршрут»

### 4.2 Рейтинговый блок

**FR-4.2.1** Рейтинг отображается в трёх разрезах одновременно:
- За всё время
- За последние 6 месяцев
- За последние 3 месяца

**FR-4.2.2** Распределение оценок отображается в виде горизонтальных полос: 5★ N отзывов, 4★ N, 3★ N, 2★ N, 1★ N.

**FR-4.2.3** Если рейтинг за последние 3 месяца значительно ниже общего — отображается предупреждение «Качество могло снизиться — смотри свежие отзывы».

### 4.3 Кнопки действий

**FR-4.3.1** Кнопка «Записаться» — активна только если сервис подключил онлайн-запись. Иначе отображается «Позвонить».

**FR-4.3.2** Кнопка «Написать отзыв» — для авторизованных клиентов с верификацией уровня 1+. Для гостя — открывает форму регистрации.

**FR-4.3.3** Кнопка «Пожаловаться на карточку» — для сообщения о неверных данных (адрес изменился, сервис закрылся и т.д.).

## 5. Система отзывов

### 5.1 Написание отзыва

**FR-5.1.1** Написать отзыв может только авторизованный пользователь с верификацией уровня 1 (подтверждённый телефон) и ролью `client`.

**FR-5.1.2** Форма отзыва содержит:
- Оценка 1–5 звёзд (обязательно)
- Дата визита — выбор из календаря, не позднее сегодняшнего дня (обязательно)
- Тип выполненной услуги — выбор из списка услуг сервиса или ввод вручную (обязательно)
- Марка и модель авто (опционально)
- Текст отзыва — минимум 50 символов (обязательно)
- Фото результата — до 5 фото, форматы JPG/PNG/HEIC, максимум 10 МБ каждое (опционально)

**FR-5.1.3** Один аккаунт может оставить один отзыв на один сервис. Повторный отзыв возможен не ранее чем через 6 месяцев после предыдущего.

**FR-5.1.4** После отправки отзыв проходит автоматическую проверку на спам (ключевые слова, паттерны) и публикуется в течение 5 минут если не выявлено нарушений. При подозрении на спам — уходит на ручную модерацию.

### 5.2 Отображение отзывов

**FR-5.2.1** Отзывы на карточке сервиса разделены на вкладки:
- «Все» — хронологически, свежие сверху
- «Положительные» — оценка 4–5
- «Отрицательные» — оценка 1–3

**FR-5.2.2** Сортировка внутри вкладок: по дате (по умолчанию) / по полезности (количество лайков).

**FR-5.2.3** Каждый отзыв отображает:
- Имя автора (или «Аноним» если пользователь выбрал скрыть имя)
- Бейдж верификации
- Оценка звёздами
- Дата визита и дата написания отзыва
- Тип услуги и марка авто
- Текст отзыва (с кнопкой «Читать полностью» если более 300 символов)
- Фотографии — превью с раскрытием в лайтбокс
- Кнопка «Полезно» (счётчик лайков)
- Кнопка «Пожаловаться» на отзыв
- Ответ поставщика (если есть) — выделен отдельным блоком с бейджем «Ответ владельца»

### 5.3 Неудаляемость отзывов

**FR-5.3.1** Отзыв не может быть удалён ни автором, ни поставщиком услуг.

**FR-5.3.2** Автор может отредактировать текст в течение 24 часов после публикации. После этого — только через обращение к администратору.

**FR-5.3.3** Администратор может скрыть отзыв только при наличии явного нарушения: нецензурная лексика, персональные данные третьих лиц, доказанная накрутка. Скрытый отзыв не удаляется — помечается как «Скрыт модерацией» и виден только администраторам.

**FR-5.3.4** Поставщик может подать жалобу на отзыв с указанием причины. Модератор рассматривает жалобу в течение 48 часов. Решение фиксируется.

### 5.4 Ответ поставщика на отзыв

**FR-5.4.1** Поставщик может оставить один публичный ответ на каждый отзыв. Ответ можно редактировать в течение 1 часа после публикации.

**FR-5.4.2** Ответ поставщика отображается непосредственно под отзывом, выделен визуально, содержит бейдж «Официальный ответ».

**FR-5.4.3** Ответ на отзыв доступен только в платном тарифе поставщика (фаза 2).

## 6. Тикеты и форум вопросов

### 6.1 Создание тикета

**FR-6.1.1** Тикет может создать авторизованный клиент с верификацией уровня 1+.

**FR-6.1.2** Форма создания тикета:
- Заголовок — краткое описание вопроса, 10–100 символов (обязательно)
- Описание — подробное описание проблемы или вопроса, минимум 50 символов (обязательно)
- Категория — выбор из списка (Диагностика, Кузов, Электрика, ТО, Шины, Документы, Выбор сервиса, Другое)
- Марка и модель авто (обязательно)
- Год выпуска авто (опционально)
- Прикрепление фото — до 5 фото (опционально)
- Привязка к конкретному сервису — поиск по названию (опционально)
- Геолокация — «искать ответы от сервисов рядом со мной» (опционально)

**FR-6.1.3** Тикет публикуется немедленно после базовой антиспам-проверки.

### 6.2 Лента тикетов

**FR-6.2.1** Публичная страница `/forum` отображает все тикеты с фильтрами:
- По категории
- По статусу (открытый / решённый)
- По марке авто
- По городу / геолокации

**FR-6.2.2** Каждый тикет в ленте показывает: заголовок, категорию, марку авто, дату создания, количество ответов, статус.

**FR-6.2.3** Тикеты сортируются: новые сверху по умолчанию, опционально — по количеству ответов.

### 6.3 Ответы на тикеты

**FR-6.3.1** Отвечать на тикет могут пользователи с ролью `provider` или `expert`. Клиенты не могут отвечать — только создавать тикеты и голосовать за ответы.

**FR-6.3.2** Ответ содержит: текст (минимум 30 символов), опциональное фото, бейдж роли отвечающего (название сервиса или специализация эксперта).

**FR-6.3.3** Автор тикета может отметить один ответ как «Лучший». Лучший ответ отображается первым и визуально выделен.

**FR-6.3.4** Все пользователи (включая гостей) могут поставить лайк ответу. Лайки формируют репутацию отвечающего эксперта или сервиса.

**FR-6.3.5** Автор тикета закрывает его статус кнопкой «Вопрос решён». Закрытый тикет доступен для чтения, но не принимает новых ответов.

### 6.4 Тикеты в кабинете поставщика

**FR-6.4.1** Поставщик видит ленту тикетов отфильтрованную по своим категориям услуг — автоматически, без ручной настройки.

**FR-6.4.2** Система уведомляет поставщика о новых тикетах в его категории: пуш в кабинете + email-дайджест раз в день.

**FR-6.4.3** Если тикет привязан к конкретному сервису поставщика — приоритетное уведомление (мгновенно).

**FR-6.4.4** Ответы поставщика на тикеты отображаются в его карточке сервиса как показатель активности и экспертизы.

## 7. Онлайн-запись

### 7.1 Настройка расписания поставщиком

**FR-7.1.1** Поставщик в личном кабинете настраивает рабочие дни и часы приёма.

**FR-7.1.2** Поставщик создаёт временные слоты: длительность слота (30 / 60 / 90 / 120 минут), количество одновременных записей в один слот.

**FR-7.1.3** Поставщик может заблокировать конкретные даты или временные интервалы (праздники, техническое обслуживание).

**FR-7.1.4** Расписание настраивается на срок до 60 дней вперёд.

### 7.2 Запись клиента

**FR-7.2.1** Кнопка «Записаться» доступна на карточке сервиса если поставщик подключил онлайн-запись.

**FR-7.2.2** Форма записи:
- Выбор услуги из списка услуг сервиса
- Выбор даты из доступного календаря (недоступные даты задизейблены)
- Выбор временного слота из доступных на выбранную дату
- Марка, модель и год авто (обязательно)
- Комментарий — описание проблемы (опционально)
- Подтверждение контактных данных: имя, фамилия, телефон (подставляются из профиля, редактируемы)

**FR-7.2.3** После подтверждения клиент получает SMS с деталями записи: название сервиса, адрес, дата, время, услуга.

**FR-7.2.4** Клиент может отменить запись не позднее чем за 2 часа до визита через личный кабинет. При более поздней отмене — система фиксирует «неявку» (влияет на возможность повторной записи).

### 7.3 Расписание в кабинете поставщика

**FR-7.3.1** Раздел «Расписание» отображает записи в двух режимах: список (таблица) и календарь (день / неделя).

**FR-7.3.2** Каждая запись в расписании содержит:
- Дата и время
- Имя и фамилия клиента
- Номер телефона клиента (кликабельный — открывает звонок)
- Выбранная услуга
- Марка, модель и год авто
- Комментарий клиента
- Статус: ожидает подтверждения / подтверждена / выполнена / отменена / неявка

**FR-7.3.3** Поставщик может подтвердить или отклонить запись. При отклонении — обязателен комментарий причины, клиент получает SMS.

**FR-7.3.4** Автоматическое SMS-напоминание клиенту отправляется за 2 часа до визита.

**FR-7.3.5** После визита поставщик отмечает запись как «Выполнена». Клиент получает уведомление с предложением оставить отзыв.

**FR-8.1.2** Клиент может добавить «Мой гараж» — список своих автомобилей: марка, модель, год, пробег. Используется для автозаполнения при записи и написании отзывов.

### 8.2 Мои отзывы

**FR-8.2.1** Список всех отзывов написанных клиентом: сервис, оценка, дата, статус (опубликован / на модерации / скрыт).

### 8.3 Мои тикеты

**FR-8.3.1** Список тикетов созданных клиентом с индикатором количества новых ответов.

### 8.4 Мои записи

**FR-8.4.1** История записей: предстоящие и прошедшие. Для предстоящих — кнопка отмены. Для прошедших — кнопка «Оставить отзыв» (если отзыв ещё не написан).

**FR-9.2.2** Форма ответа на отзыв — открывается по кнопке «Ответить» под каждым отзывом. Отправленный ответ публикуется немедленно.

**FR-9.3.3** Форма ответа на тикет — непосредственно из кабинета, без перехода на публичную страницу.

Описано в разделе 7.3.

- Категория и подкатегории
- Адрес (изменение проходит модерацию)
- Телефон и сайт

**FR-9.5.2** QR-код — автоматически генерируется для каждого сервиса. Ведёт на форму написания отзыва для конкретного сервиса. Доступен для скачивания в PNG и PDF для печати.

**FR-9.5.3** Изменение адреса требует повторного прохождения верификации — во избежание переноса рейтинга на другой сервис.

### 12.2 SEO-требования

**FR-12.2.3** Структурированные данные (JSON-LD): `LocalBusiness`, `Review`, `AggregateRating` — для отображения рейтинга в результатах поиска.

**FR-12.2.4** Автоматическая генерация `sitemap.xml` с приоритетами: карточки сервисов с наибольшим количеством отзывов имеют наивысший приоритет.
