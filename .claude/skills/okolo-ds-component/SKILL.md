# Создание ds-компонента (okolo)

Эталон, на котором всё отлажено: `src/app/shared/ds/card/` (+ `README.md`).

## 0. Куда кладём

`shared/ds` — только **generic** (domain-free). Лакмус: знает доменную модель (`Place`, `Rating`) → это `ui-kit`/`features`, не ds. Формы/CVA (`@angular/forms`, `ControlValueAccessor`) — это framework, остаётся в ds.

## 1. Слайс-структура

```
shared/ds/<name>/
  components/<name>/
    <name>.component.ts / .html / .scss / .spec.ts
  directives/<dir>/
    <dir>.directive.ts
    <dir>.directive.spec.ts        # spec на КАЖДУЮ директиву
  types/
    <name>-<aspect>.type.ts        # один тип = один файл
  index.ts                          # публичная бочка
  README.md                         # по образцу ds/card
```

Каждая директива — в своей папке со своим spec. Общую логику директив выносим в абстрактную базу (напр. `*-slot.directive.ts`), её наследуют, но **не экспортируют**.

## 2. Компонент

- standalone (по умолчанию), `changeDetection: ChangeDetectionStrategy.OnPush`
- `selector: 'ds-<name>'`
- инпуты — signal `input()`, объявление `public readonly`
- варианты/состояния — через host-биндинги классов: `host: { '[class.glass]': "appearance() === 'glass'", '[class.interactive]': 'interactive()' }`
- булевы флаги — `input(false, { transform: booleanAttribute })`
- типы-объединения выносим в `types/*.type.ts` с именем `TDs<Name><Aspect>` (не инлайн)

## 3. Система размеров (если компонент размерный)

- общий тип `TDsSize = 'S' | 'M' | 'L' | 'XL'` из `@shared/models` (только **заглавные**)
- инпут `size = input<TDsSize | null>(null)` — `null` = не задавать свой, **наследовать**
- host: `'[class]': 'size()'` — ставит класс размера на хост (или ничего)
- наследование — через `:host-context(.S)` (срабатывает, если класс на хосте ИЛИ любом предке); дефолт `M` задан в базовом `:host`
- значения размера прокидываем через приватные переменные `--ds-<name>-pad` / `--ds-<name>-radius`, которые потребляются в объявлениях. Так размерный радиус выигрывает у радиуса материала (миксина) независимо от специфичности.
- осознанный компромисс: при вложенных конфликтующих контекстах выигрывает не ближайший предок, а правило ниже по коду — задокументировать в шапке scss.

## 4. SCSS

- `@use 'surfaces' as surf;` — работает за счёт `stylePreprocessorOptions.includePaths: ['src/styles/design-system']` в `angular.json`
- только токены: `var(--space-*)`, `var(--radius-*)`, `var(--c-*)`, миксины `surf.ds-*`. Литералы — нельзя; нет токена → завести в `styles/design-system`.
- **не** импортировать в компонент партиалы с `:root` (color/layout/size/...) — они продублируют токены в каждом компоненте. Переменные уже объявлены глобально, просто пользуемся.

## 5. Директивы-маркеры слотов

- атрибутный селектор (`[dsCardHeader]`) служит и маркером для `ng-content select`, и носителем инпутов
- стили — host-биндингами инлайном, директива самодостаточна (без внешнего CSS)
- значения вроде `align` — логические (`start|center|end`), которые 1:1 валидные CSS-ключевые слова (пишутся прямо в `[style.text-align]`, без маппинга)
- общие host-биндинги/инпуты — в абстрактной базе, конкретные директивы её наследуют

## 6. Публичный API (index.ts)

- экспортируем: компонент, конкретные директивы, публичные типы
- **не** экспортируем: абстрактные базы, внутренние host-консты
- **без** бандл-массивов — потребитель импортирует ровно то, что в шаблоне

## 7. Тесты (vitest)

- host-компонент с **сигналами** для инпутов: `readonly x = signal(...)`, в шаблоне `[x]="x()"`. Меняем через `x.set()` → `detectChanges()`. Обычные поля между двумя `detectChanges` дают `NG0100`.
- проверяем классы / атрибуты / инлайн-стили на host-элементе (`el.classList`, `el.getAttribute`, `el.style.*`)
- тестовую директиву в спеке тоже именуем с префиксом `ds` (eslint форсит префикс на весь `shared/ds`, включая спеки)
- запуск: `ng test --no-watch`

## 8. README

Документируем **только публичный API** (абстрактные базы и внутренние консты — нет). Разделы: импорт, базовое использование, таблицы инпутов, размеры/наследование, слоты, полный пример, сводка экспортов. Эталон — `ds/card/README.md`.

## Финальный чек

`ng lint` + `ng build` + `ng test --no-watch` — всё зелёное.
